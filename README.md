# Mein Jahresplaner

Jahresplaner und Stundenjournal für das Referendariat an der Grundschule in Hessen (Schuljahr 2027/28) mit den Fächern Deutsch, Mathematik und Englisch, Jahrgänge 1–4.

Alles steckt in einer einzigen Datei: `index.html`. Die Seite braucht keinen Server und keine Installation. Sie läuft im Browser und funktioniert offline.

## Benutzen

- **Lokal:** `index.html` herunterladen und im Browser öffnen.
- **Online:** über GitHub Pages veröffentlichen (Settings → Pages → Branch `main`, Ordner `/`).

Deine Einträge werden im Browser gespeichert (localStorage, Dateien in IndexedDB). Sie verlassen dein Gerät nicht. Zum Sichern und zum Übertragen auf ein anderes Gerät dient unter **Grundlagen → Daten** der JSON-Export und -Import.

## Was drin ist

- **Start:** Countdowns (Schultage, Ferien, Unterrichtsbesuche), Heute, Als Nächstes, Aufgaben, Erfolgsglas
- **Woche und Stundenplan:** Stunden mit einem Tipp planen, dabei automatisch mit Einheit, Woche, Phase und Kompetenzen verknüpft
- **Unterrichtsbesuche:** Checkliste, Verlaufsplan, Materialien, Feedback, Entwurf-Assistent
- **Einheiten:** Unit-Planer, abgebildet auf das Kerncurriculum Hessen 2011
- **Seminare:** Mitschrift, Erkenntnisse, Aufgaben, Materialien
- **Klasse:** Tagesablauf, Stillezeichen, Murmelglas, Timer, Zufallsauswahl und Spiele für zwischendurch, alles auch als Tafelansicht
- **Unterrichtsmodus:** Phasen mit Timer für Beamer oder Tafel, an die Klassenstufe angepasst, auf Englisch in Englischstunden
- **Bibliothek:** Materialien und Ideen
- **Jahresplan, Kompetenzraster, Archiv, Grundlagen**

## Hinweise

- Die 80 Einheiten sind Vorlagen. Unter Grundlagen → Daten → „Unitplaner importieren“ lassen sie sich durch eigene ersetzen.
- Die Texte der Bildungsstandards sind eng am Kerncurriculum 2011 formuliert, aber nicht wörtlich geprüft. Unter Grundlagen → „Wortlaut bearbeiten“ lassen sie sich anpassen.
- Ferien, erster Schultag (09.08.2027 angenommen) und Hessen-Hinweise bitte mit den gültigen Vorgaben abgleichen.
